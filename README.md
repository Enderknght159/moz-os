# MOZ OS — روابط محمية

هذا المستودع يستضيف نسختين **مشفّرتين** من العرض التقديمي والبروتوتايب.

- المحتوى مشفّر بـ AES-256-GCM، ومفتاحه مشتق من كلمة المرور (PBKDF2).
- لا توجد أي بيانات عميل أو أسعار داخل الملفات بصيغة مقروءة.
- الملفات الأصلية غير المشفّرة لا تُرفع هنا.
